# Potin et al. Chilean seismic catalog — source record

The seismic application uses the relocated Chilean seismic catalog associated with Potin et al., *A Revised Chilean Seismic Catalog from 1982 to Mid-2020*, Seismological Research Letters 96(1), 484–498 (2025).

Dataset release used: https://doi.org/10.5281/zenodo.13146436

Expected file: `CHILE_SEISMICITY_RELOCATED.csv`

Expected SHA-256:

`0ca7ca6b766c805fb110178c9b08fb438b8838442efcfdf32430de8f61e58362`

The event-level catalog is not redistributed in this repository because the Zenodo record currently does not display an explicit redistribution license. Use `scripts/fetch_potin_catalog.py` to retrieve and verify the exact archive.
