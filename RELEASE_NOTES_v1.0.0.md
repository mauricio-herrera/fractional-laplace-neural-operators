# v1.0.0 — manuscript reproducibility release

First public reproducibility release for *Fractional Laplace Neural Operators*.

Includes:
- controlled operator-learning benchmark code and frozen outputs;
- independently checked secondary benchmark replication;
- Potin-based homogeneous Chilean seismic rebuild code and aggregate outputs;
- Chile/Italy epidemic reproducibility workflows including rolling temporal validation;
- provenance, licensing notes, source-data retrieval instructions, and integrity checks.

The Potin event-level catalog is intentionally not redistributed; use `scripts/fetch_potin_catalog.py`.
