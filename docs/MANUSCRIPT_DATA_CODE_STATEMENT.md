# Manuscript data and code statement

The code, frozen numerical outputs, data-provenance records, and reconstruction workflows supporting this study are available at the public repository `https://github.com/mauricio-herrera/fractional-laplace-neural-operators`. The relocated Chilean seismic catalog is obtained from Potin et al., Zenodo DOI `10.5281/zenodo.13146436`; because the source record used here does not display an explicit redistribution license, the event-level table is not republished and the repository instead provides a checksum-verified retrieval script. Epidemic source/provenance records and frozen analysis-ready files are documented in the archived release. The reproducibility archive `10.5281/zenodo.21779954` refers to the previously published CNSNS mathematical foundation, not to the present work. The immutable v1.0.0 reproducibility snapshot of the present study is archived at Zenodo, DOI `10.5281/zenodo.22837154`.
