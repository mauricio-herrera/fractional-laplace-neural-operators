# Suggested manuscript statement

## Data and code availability

The code, frozen numerical outputs, analysis scripts, data-provenance records, and documentation supporting this study are publicly available in the version-controlled repository https://github.com/mauricio-herrera/fractional-laplace-neural-operators. A version-specific archival snapshot of the reproducibility package is deposited in Zenodo.

The primary seismic analysis uses the relocated Chilean catalog of Potin et al. (Zenodo DOI: 10.5281/zenodo.13146436). Because the current source record does not display an explicit redistribution license, the event-level catalog is not republished in the project repository; instead, the repository provides an automated retrieval script and verifies the exact source by SHA-256 before reconstruction. The epidemic analyses use JHU CSSE/OWID historical Chile COVID-19 data and official Italian Protezione Civile regional data under their original data terms. Frozen input snapshots, provenance, and checksums are included in the archival reproducibility release where permitted.
